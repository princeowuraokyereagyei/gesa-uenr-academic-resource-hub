Admin

Upload files from your phone or computer, manage materials and forms, with no code. Changes go straight to your GitHub repo and appear on the site after 1 to 2 minutes.

1. Connect to your GitHub (one time)
  1. On github.com open Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Set an expiry (e.g. 90 days). Under Repository access choose Only select repositories and pick your hub repo.
  3. Under Permissions > Repository permissions set Contents to Read and write. Generate, copy the token, paste below.

The token stays in this browser and is sent only to GitHub. Never share it, and don't use this on a public computer. Anyone without a valid token can open this page but cannot change anything.
